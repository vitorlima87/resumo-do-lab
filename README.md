# resumo-do-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO

Aprendi um pouco sobre computação em nuvem, como por exemplo, existem 3 tipos de nuvem, a publica que se trata de um servidor que fica fora da empresa que seria um serviço do azure ou aws, temos tambem a privada que se trata de um servidor que fica dentro da empresa, entao a propria empresa tem que cuidar desse servidor e fazer as mauntenções regularmente, e por fim a hibrida que possui os dois mundos, tanto um servidor "nuvem" como um servidor fisico na empresa, esse seria o melhor cenario pois se trata dos dois mundos, tendo vantagens e desvatagens dos dois tipos de nuvem.
